# RFID出欠管理システム v2 — 学校貸出PC 導入手順

## 1. この手順書について

この手順書は、Windows向けポータブル配布物を学校貸出PCで起動するためのものです。配布物にはPC管理画面のReactビルドとFastAPI実行環境が含まれるため、Python、Node.js、pnpm、VS Code、PlatformIOのインストールは不要です。

展示PCではサンプルの学生・授業・履修データだけを使用してください。実在する学生情報、実際の出欠履歴、実カードUID、運用DB、端末tokenを配布ZIPへ入れないでください。

> **検証状態**: 開発PC上の配布物起動は確認済みです。学校貸出PC、学校のDefender/EDR/GPO、ESP32実機、Maker UNO＋RC522は未検証です。学校PCで実行できることを保証するものではありません。

## 2. 展示前に用意するもの

- `RFID-Attendance-v2-Showcase-Windows.zip`
- ESP32が起動していること
- ESP32の実際のSoftAP SSIDとWi-Fiパスワード
- ESP32のDevice IDと64桁のtoken

SSID、Wi-Fiパスワード、Device ID、tokenは機器ごとの設定です。ファームウェア作成担当者から安全な方法で受け取り、公開チャットや公開リポジトリへ貼り付けないでください。サンプル設定のSSID `RFID-Showcase` が実機でも使われているとは限りません。

## 3. ZIPの取得と展開

1. Google Driveの指定フォルダからZIPをダウンロードします。共有されていない場合は、管理者へアクセス権を依頼してください。
2. ダウンロードしたZIPを右クリックし、**すべて展開**を選びます。
3. 展開先は、現在のWindowsユーザーが書き込めるフォルダにします。例: `ドキュメント\RFIDShowcase` または `デスクトップ\RFIDShowcase`。
4. ZIP内の `RFIDShowcase` フォルダを開き、`RFIDShowcase.exe`、`Start-Showcase.cmd`、`Pair-Device.cmd`、`_internal` フォルダがそろっていることを確認します。

ZIPの中から直接実行したり、`RFIDShowcase.exe` だけを別フォルダへ移動したりしないでください。`_internal` を含むフォルダ一式が必要です。`Program Files` や学校管理の読み取り専用領域へ置かないでください。

## 4. ESP32のWi-Fiへ接続してペアリング

ESP32を使わずPC画面だけを展示する場合は、この節を飛ばして「5. 管理アプリの起動」へ進めます。

1. WindowsのWi-Fi一覧から、機器担当者が案内したESP32のSoftAP SSIDを選びます。
2. 案内されたWi-Fiパスワードを入力して接続します。「インターネットなし」と表示されても、この展示用ネットワークでは通常の状態です。接続を維持してください。
3. PCのIPv4設定は**自動取得（DHCP）**のままにします。PCへ固定IPを設定する必要はありません。
4. 展開した `RFIDShowcase` フォルダの `Pair-Device.cmd` をダブルクリックします。
5. ESP32のDevice IDと64桁のtokenを入力します。tokenは入力中に画面へ表示されません。
6. 「このWindowsユーザー用に保存しました」と表示されたらペアリング設定は保存されています。

ペアリングファイルは `Data\Showcase\device-pairing.json` に保存され、Windows DPAPIで現在のWindowsユーザー向けに保護されます。別のWindowsユーザーやPCへファイルだけをコピーしても復号できないため、利用するユーザーごとにペアリングしてください。ペアリング処理自体はESP32への疎通確認を行いません。起動後に管理画面のESP32管理で状態を確認します。

## 5. 管理アプリの起動

1. `Start-Showcase.cmd` をダブルクリックします。
2. コンソールに `展示モード起動` と表示され、ブラウザが開くまで待ちます。
3. ブラウザが開かない場合は、アドレス欄へ `http://127.0.0.1:8000/` と入力します。
4. ダッシュボードに登録学生3名、授業「文化祭デモ授業」が表示されることを確認します。

初回は展示用DBがないため、アプリがダミー学生3名・授業1件・履修3件を作ります。次回以降は既存DBを使い、データを自動削除しません。テスト用カードUIDは `D0A00001`、`D0A00002`、`D0A00003` です。ESP32が使えない場合は、出席受付で入力方式 `MOCK` を選び、読取開始後にこれらのUIDを手入力して画面を案内できます。

## 6. ESP32の状態確認と出席受付

1. 管理画面の **ESP32管理** を開き、接続状態、UNO状態、保留イベント数、PCと端末のキャッシュ同期状態を確認します。
2. ESP32が未接続の場合は、PCがESP32のWi-Fiへ接続中か、SSIDとペアリング情報が正しいかを確認してから画面を再読込します。
3. **出席受付** を開き、授業「文化祭デモ授業」を選んで **授業回を開始** を押します。
4. 入力方式 `ESP32` を選び、**受付開始** を押します。成功すると授業回がESP32へ紐付き、端末側の読取が有効になります。
5. RFIDカードを読み取ります。PC接続中はESP32のイベントが同期され、出欠の正式な判定と保存はPC側で行われます。
6. **ESP32管理** で状態と同期Inboxを確認します。展示用カード以外のUIDは登録済みとして扱われない場合があります。

受付を一時停止・再開する場合は **ESP32管理** の **読取停止** / **読取再開** を使います。授業回を終了するときはPCをESP32のWi-Fiへ接続したまま **出席受付** で **受付終了** を押してください。終了処理はESP32を停止し、端末に残るイベントを同期してから授業回を閉じます。同期に失敗した場合は授業回を閉じられないことがあります。Wi-Fi接続を復旧してESP32管理の状態を再確認し、もう一度終了してください。

PCが切断中にESP32が読んだデータは仮受付です。PCへ同期されるまでは正式な出欠結果として扱わないでください。

## 7. アプリの終了

アプリを起動した黒いコンソール画面を選び、**Enter** を押します。サーバーが停止した後にコンソールが閉じます。タスクマネージャーから強制終了すると、終了処理が完了しない場合があります。

展示DBとログは配布フォルダ内に残ります。

- DB: `Data\Showcase\attendance.db`
- 起動ログ: `Data\Showcase\Logs\launcher.log`
- アプリログ: `Data\Showcase\Logs\application.log`

展示を終えてデータを消去する場合は、アプリ終了後に `Data\Showcase` フォルダを削除してください。学校のPC管理ルールがある場合は、管理者の指示に従ってください。

## 8. 権限・ネットワーク・セキュリティ

- 通常の展開、起動、DB/ログ作成に管理者権限は必要ない設計です。書き込み可能なユーザーフォルダを使用してください。
- PC管理画面は `127.0.0.1:8000` のみに接続します。通常、Windowsファイアウォールの受信許可や固定IPは不要です。
- ESP32との通信はPCから `192.168.4.1` へのローカルネットワーク通信です。学校のネットワーク制御やセキュリティ製品がこれを禁止する場合があります。
- Windows Defender、ウイルス対策、EDR、ファイアウォール、GPO、WDAC、AppLockerを無断で無効化したり、除外登録したりしないでください。
- SmartScreenや学校の制御で警告・実行拒否が出た場合は実行を止め、表示内容とログを学校管理者へ確認してください。管理者が許可する署名済み配布方法が必要な場合があります。
- 未署名EXEがブロックされた場合、ユーザーだけで安全に解除できる手順は確立していません。
- Device ID、token、Wi-Fiパスワードをログや画面写真へ残さないでください。カードUIDは複製可能で、本人確認の強い根拠にはなりません。

## 9. トラブルシューティング

| 症状 | 確認すること |
| --- | --- |
| 起動してすぐ閉じる / 画面が開かない | `Data\Showcase\Logs\launcher.log` と `application.log` を確認し、フォルダに書き込み可能か確認します。 |
| ポート8000が使用中 | 他の同じ展示アプリを終了し、再起動します。既存の別アプリが使っている場合は学校管理者に相談します。 |
| ダミーデータが表示されない | ダッシュボードを再読込します。既存の `attendance.db` がある場合、自動でダミーデータを追加しない仕様です。 |
| ESP32が未接続 | ESP32の電源、SoftAP SSID、Wi-Fiパスワード、Windowsの接続先、Device ID、tokenを確認し、ESP32管理を再読込します。 |
| 授業回を開始できない / 閉じられない | 未終了の授業回がないか確認します。ESP32使用時は接続を復旧し、端末状態と未同期イベントを確認してから再試行します。 |
| 実行ファイルが隔離・拒否された | セキュリティ機能を変更せず、学校管理者へファイル名、警告画面、ログを提示します。 |
| ZIPを展開した場所で書き込みエラー | `ドキュメント` などユーザーが書き込める場所へフォルダ一式を移して再試行します。 |

## 10. 未検証項目

- 学校貸出PCのクリーンなWindows環境での導入・起動
- Defender、SmartScreen、EDR、GPO、WDAC、AppLockerとの適合
- 学校PCからESP32 SoftAPへ接続できること
- ESP32とMaker UNO＋RC522の実機連携、UART、電源・レベル変換
- 通信断、電源断、長時間運用、展示終了時の復旧
- 書き込みが禁止されたフォルダでの起動失敗表示とログ保存
