## 1. 記載ルール

本仕様書では、対応するテストコードが存在するものだけファイル名・関数名を記載する。未実装・未実施のテストに架空の関数名は付けず、対応コードを `—（未実装）` とする。

| 実施状況 | 意味 |
|---|---|
| PASS | 今回実行し、期待結果を満たした |
| FAIL | 今回実行し、期待結果を満たさなかった |
| PARTIAL | 類似範囲の一部だけを検証した |
| NOT RUN | 今回実行していない |
| BLOCKED | 外部条件で実行できなかった |
| USER-VERIFIED | 今回の自動実行ではなくユーザーの手動確認 |
